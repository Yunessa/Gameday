Sources & Credits

What this page is built on, and where the data comes from.

Data

Live scores, schedules, and broadcast info are pulled directly from ESPN's public scoreboard endpoints (site.api.espn.com) by your own browser, refreshed roughly every 25 seconds while the page is open. This is an unofficial, undocumented ESPN endpoint — not a paid or licensed feed — so data can occasionally lag, go blank during ESPN maintenance, or change format without notice.

Independence

This is a fan-made tool built for Cheba Hut's Pearl Street regulars. It is not affiliated with, endorsed by, or operated by ESPN, the NFL, NCAA, NBA, MLB, NHL, MLS, the Premier League, the PGA Tour, or Cheba Hut Toasted Subs. Team names and abbreviations are shown for identification only.

Icons

Sport and UI icons are native emoji (⭐🏈🏀⚾🏒⚽⛳🔍📺) rendered by the visitor's own device/OS — no icon font or image library loaded, and no external icon service is called.

Code

Single static HTML file — no build step, no framework, no analytics or tracking of any kind. Team favorites are stored only in your own browser's local storage; nothing is sent to a server other than the score requests to ESPN described above.
